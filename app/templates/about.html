PawConnect Layihəsi Haqqında

SW01 (Software Projects) kateqoriyası üzrə hazırlanmış tamfunksiyalı, müasir və sosial əhəmiyyətli heyvan sahibləndirmə ekosistemi.

Problem (Niyə bu layihə?)

Şəhərlərdə və regionlarda sığınacaqlar pərakəndə fəaliyyət göstərir. Sahiblənmək istəyən vətəndaşlar heyvanların sağlamlıq, peyvənd və xarakter məlumatlarını tapa bilmir. Nəticədə bir çox heyvan adaptasiya ola bilməyib yenidən küçəyə buraxılır.

Həll Yolu (PawConnect)

Vahid rəqəmsal reyestr, hər bir heyvan üçün rəqəmsal peyvənd pasportu, sığınacaqlar üçün idarəetmə paneli və ailə ilə heyvanın uyğunluğunu hesablayan Smart Matcher alqoritmi.

Proqram Təminatı Arxitekturası (D5 Record)

Tələb olunan modul bölgüsü: User Interface $\rightarrow$ Application Logic $\rightarrow$ Data Services $\rightarrow$ Database

1. İstifadəçi İnterfeysi

Frontend (UI)

Tailwind CSS, Jinja2, Lucide Icons, Responsive SPA/Multi-page interfeys

2. Marşrutlaşdırma

Web & API Routers

FastAPI Asinxron marşrutlar: Pets, Adoptions, Vaccines, Smart Quiz

3. Biznes Məntiqi

Application Logic

Pydantic validasiyası, Smart Matcher uyğunluq balı hesablama alqoritmi

4. Verilənlər Bazası

SQLite / PostgreSQL

SQLAlchemy ORM modelləri (Shelter, Pet, VaccineRecord, AdoptionApplication)

Şagirdlərin Münsiflər Qarşısında Təqdimat İzahı (SW01.5.7)

10-14 yaş qrupu üçün aydın Input $\rightarrow$ Processing $\rightarrow$ Output strukturu

Giriş (Input): İstifadəçi saytda axtarış edir, müraciət formasını doldurur və ya 4 suallıq testi tamamlayır.
Emal (Processing): FastAPI backend daxil olan parametrləri `schemas.py` ilə yoxlayır, `api_quiz.py` alqoritmi ailənin şəraiti ilə heyvanın xüsusiyyətlərini müqayisə edərək 0-100% arası uyğunluq dərəcəsi çıxarır.
Çıxış (Output): Sistem uyğun heyvanları dərəcələndirərək ekrana gətirir, sığınacaq əməkdaşına isə müraciəti idarə etmək üçün bildiriş ötürür.

Annex 4.5 — Açıq Mənbə və Alət Bəyannaməsi

• Kitabxanalar və Freymvorklar: FastAPI (Python), Uvicorn, SQLAlchemy, Pydantic, Jinja2, Tailwind CSS, Lucide Icons.

• Süni İntellekt Dəstəyi: Qayda SW01.7.4 və O4.5 uyğun olaraq layihənin kod strukturlaşdırılmasında, məlumat bazasının generasiyasında və çoxdilli lüğətin tərtibində süni intellekt köməkçi kimi iştirak etmiş, bütün məntiq və müdafiə şagirdlər tərəfindən mənimsənilmişdir.

• Məlumat Təhlükəsizliyi: Qayda SW01.4 uyğun olaraq heç bir real şəxsi gizli məlumat istifadə edilməmiş, bütün test məlumatları sintetik olaraq təhlükəsiz şəkildə yaradılmışdır.
